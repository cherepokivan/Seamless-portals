# Seamless Portals — Minecraft 26.2 Fabric Client Mod

**Seamless Portals** — это высококачественный клиентский мод для Minecraft Java Edition 26.2, реализующий визуально реалистичные сквозные порталы в Незер («живое окно» в другое измерение).

## Основные особенности

- **Настоящий рендеринг мира**: Портал не является статической текстурой или заранее отрендеренным изображением [1]. Вы видите реальный мир Незера или Оверворлда с блоками, лавой, водой, мобами и туманом [1].
- **Двусторонний рендеринг (Оверворлд ↔ Незер)**: Мод автоматически определяет измерение назначения и рендерит его. Вы можете видеть Незер из Оверворлда и Оверворлд из Незера [1].
- **Корректная ориентация**: Система камер учитывает ориентацию как исходного, так и целевого портала, обеспечивая бесшовный визуальный переход независимо от того, как повернуты порталы [1].
- **Истинная перспектива и параллакс**: При перемещении игрока влево, вправо или под углом перспектива через портал изменяется естественным образом, создавая эффект настоящего окна в обоих направлениях.
- **Зеркальный режим (Mirror Mode)**: Экспериментальный режим, позволяющий видеть отражение текущего мира в портале.
- **Расширенная отладка**: Нажатие **F8** отображает не только текстовую информацию, но и визуализирует границы порталов и их нормали непосредственно в мире [7].
- **Чисто клиентский мод**: Мод работает на любых стандартных ванильных или Paper серверах без необходимости установки мода на сервер [2].
- **Опциональная интеграция с Paper**: Опциональный плагин `seamless-portals-paper` может быть установлен на сервер Paper для минимальной синхронизации метаданных без нагрузки на TPS сервера [3].
- **Агрессивная оптимизация**: Включает фрустум-окклюжн куллинг, динамическое разрешение кадрового буфера (framebuffer), лимитирование частоты обновления кадров портала и управление бюджетом рендеринга.

## Требования

- **Minecraft Java Edition**: 26.2
- **Fabric Loader**: 0.19.3 или новее [4]
- **Fabric API**: 0.150.1 или новее [5]
- **Java**: Java 25 (рекомендуется для Minecraft 26.2) [6]

## Установка

1. Скачайте и установите **Fabric Loader** для Minecraft 26.2 [4].
2. Поместите файл `fabric-api-*.jar` в папку `mods`.
3. Соберите мод с помощью `./gradlew build` и поместите `build/libs/seamless-portals-1.0.0.jar` в папку `mods`.

## Автоматическая сборка (CI/CD)

В проект добавлена поддержка **GitHub Actions**. При каждом пуше в ветку `main` или создании Pull Request, GitHub автоматически:
- Устанавливает JDK 25.
- Собирает Fabric мод и Paper плагин.
- Загружает готовые `.jar` файлы в качестве артефактов сборки.

Конфигурация находится в `.github/workflows/build.yml`.

## Управление и горячие клавиши

- **F7** — Включить / выключить мод Seamless Portals.
- **F8** — Открыть подробный отладчик производительности (Debug Overlay / Profiler).

## Конфигурация

Мод создает файл конфигурации в `config/seamless-portals.json`, где вы можете настроить качество рендеринга, частоту обновления, дальность прорисовки порталов и визуальные эффекты (искажение, свечение, частицы).
